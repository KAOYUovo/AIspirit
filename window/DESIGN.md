# Windows 桌面精灵设计规范

> 设计关键词：柔和、灵动、低打扰、可掌控。正式精灵形象由画师创作；开发占位资源只能用于工程调试，MVP 验收至少包含两套可切换的动态画师角色包。

## 1. 视觉基调与主色调

### 1.1 色彩

| Token | 色值 | 用途 |
|---|---:|---|
| `color.primary` | `#8B7CFF` | 主按钮、选中态、关键反馈 |
| `color.primaryHover` | `#7667EA` | 主按钮悬停 |
| `color.accent` | `#FFB7C5` | 精灵情绪、点缀与奖励反馈 |
| `color.bg.panel` | `#F8F7FF` / 94% | 浮层、设置面板 |
| `color.bg.elevated` | `#FFFFFF` | 卡片和菜单 |
| `color.text.primary` | `#29263A` | 主要文字 |
| `color.text.secondary` | `#716D83` | 次要说明 |
| `color.success` | `#45B88A` | 成功 |
| `color.warning` | `#F2A93B` | 降级、非阻塞异常 |
| `color.error` | `#E45C6B` | 错误 |
| `color.focus` | `#5B8CFF` | 键盘焦点环 |

深色模式不进入首个 MVP；代码中必须使用语义 token，禁止在业务组件散落硬编码色值，以便后续增加主题。

### 1.2 字体与尺度

- 字体：`Segoe UI Variable`，回退 `Segoe UI`。
- 正文 14 px / 20 px，辅助文字 12 px / 18 px，标题 18 px / 26 px。
- 间距基数 4 px；常用间距为 8、12、16、24 px。
- 面板圆角 16 px，按钮 10 px，气泡 14 px。
- 最小可点击区域 32×32 px；主要操作建议 40 px 高。

## 2. 组件复用规范

所有 UI 通过共享组件和 design tokens 构建：

| 组件 | 复用规则 |
|---|---|
| `SpiritWindow` | 只承载透明窗口、命中测试和精灵画面，不放业务设置页 |
| `SpiritRenderer` | 统一渲染 idle/react/drag/loading/fallback，不由页面自行切帧 |
| `SpeechBubble` | 最多两行、单行建议 ≤ 18 个汉字，自动消失，可被新消息替换 |
| `ContextMenu` | 所有桌宠右键入口统一；危险操作“退出”与普通操作分组 |
| `FloatingPanel` | 外观、未来番茄钟与设置共用容器、阴影、标题栏和关闭行为 |
| `PrimaryButton` / `SecondaryButton` / `IconButton` | 禁止页面自定义按钮视觉 |
| `AppearanceCard` | 统一缩略图、名称、选中态、不可用态 |
| `StatusView` | 统一 loading / empty / error / degraded 的布局与文案结构 |
| `Toast` | 只用于非阻塞、无需立即决策的反馈，同类消息去重 |

组件必须支持鼠标与键盘；设置面板内可交互元素必须有可见焦点态和可访问名称。

### 2.1 画师角色包规范

- 每套角色使用透明背景、统一画布和统一脚底锚点；角色不得因状态切换左右漂移或缩放跳变。
- MVP 动画集合：`idle`（循环）、`react`（单次）、`drag`（循环或保持）、`fallback`（静态）。
- `idle` 至少表现呼吸或眨眼；建议拆成多个低频变体，播放器随机选择但不得连续高频播放。
- 单个动画应提供首帧预览；资源加载时先显示预览，再无缝进入动态播放。
- 缩略图与角色包绑定，列表不得使用运行时随机截帧，避免视觉不一致。
- 角色作者、版权归属和允许的使用范围必须随 manifest 保存；未经授权不得改色、拆件或二次分发。

## 3. 窗口与层级

- 精灵窗口：透明、无边框、按内容命中测试；透明像素尽可能点击穿透。
- 默认置顶于普通窗口，但不得压过全屏应用、系统安全界面或系统菜单。
- 精灵不主动获取键盘焦点；用户打开面板时，面板才可获得焦点。
- 气泡位于精灵上方，靠近屏幕边缘时自动翻转或收缩。
- 面板默认 360×480 px，可随 DPI 缩放；必须完全落在当前工作区。
- 托盘菜单是精灵隐藏后的可靠恢复入口。

## 4. 关键交互动效

### 4.1 入场

- 300–450 ms，透明度 0→1，位移 8 px→0。
- 首次启动可附加一次轻微弹性；后续启动减少动作，避免打扰。

### 4.2 空闲

- 3–6 秒一个低频呼吸或眨眼循环。
- 动画之间保留静止区间；禁止持续大幅移动、闪烁或高帧率无意义循环。

### 4.3 点击回应

- 按下 0–80 ms 内缩放至 0.96，释放回弹至 1.0。
- 随后播放 600–1200 ms 回应动作；连续点击在 300 ms 内合并，避免动画堆积。

### 4.4 拖动

- 指针按下并移动超过 4 px 后进入 dragging。
- 拖动时轻微上浮 4 px并增加阴影；暂停 idle 动画。
- 释放后 160–220 ms 回落；若越界，使用 200 ms 动画回到安全区。

### 4.5 更换形象

- 选中后立即更新卡片状态。
- 精灵使用 180 ms 淡出 + 180 ms 淡入，不允许白屏。
- 加载失败则保留旧外观并显示非阻塞错误，不切到空画面。
- 切换的是整套角色包及其全部动态状态；MVP 不要求把服装部件实时叠加到角色骨骼上。

### 4.6 减少动态效果

尊重 Windows“动画效果”辅助设置；关闭时移除弹性、位移和循环呼吸，仅保留必要的瞬时状态切换。

## 5. 状态视觉规范

### 5.1 加载中

- 精灵资源加载：优先显示内置静态轮廓，不使用覆盖桌面的全屏 loading。
- 面板加载：使用 3 个与内容结构一致的骨架卡片；超过 2 秒显示“正在准备精灵外观”。
- 加载状态不阻止隐藏和退出。

### 5.2 空数据

- 使用精灵小插图、标题“还没有可用外观”、说明“可以恢复内置外观继续使用”。
- 主操作：“恢复内置外观”；不展示无效空白列表。
- 空状态不自动联网下载内容。

### 5.3 接口/服务报错

MVP 没有网络接口；这里的“接口”包括本地设置与资源服务：

- 可恢复错误：面板内嵌 `StatusView` 或 Toast，提供“重试”。
- 资源错误：保留最后可用外观，并展示“这个外观暂时无法使用”。
- 设置保存错误：Toast“设置暂未保存，本次仍可继续使用”。
- 不可恢复错误：小型对话框说明原因，提供“查看日志位置”和“退出”；禁止无限 loading。
- 错误文案不得显示堆栈、内部异常类型或完整本地路径。

### 5.4 降级状态

- 默认静态精灵正常可拖动、可隐藏、可退出。
- 可在“关于/诊断”处显示黄色状态点；不持续弹窗。
- 降级恢复后自动回到 idle，不要求重启。

## 6. 文案规范

- 语气友好、短句、不过度拟人化索取情感。
- 不使用“你已经很久没理我”等负罪感文案。
- 操作名称直接：显示精灵、隐藏精灵、外观、关于、退出。
- 错误文案包含“发生了什么 + 用户还能做什么”，不责怪用户。

## 7. 设计验收

- 100%、125%、150%、200% DPI 下无遮挡、无模糊文本、命中区域正确。
- 单屏、多屏、主屏切换后精灵和面板均在可见工作区。
- 透明区域不出现黑底/白边；精灵轮廓无明显锯齿。
- 鼠标主流程完整；设置面板可仅用键盘完成切换外观与关闭。
- loading、empty、error、degraded 四态均有独立可复现入口。
- 减少动态效果开启时，无持续非必要动画。
- 两套画师角色的动画状态完整，锚点稳定，播放循环无明显跳帧或空白帧。
